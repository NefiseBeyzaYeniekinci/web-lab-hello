## Kurulum ve Çalıştırma
Projeyi yerel bilgisayarınızda çalıştırmak için şu komutları sırayla uygulayabilirsiniz:

1. Bağımlılıkları yükleyin:
   `npm install`

2. Uygulamayı başlatın:
   `npm run dev`
